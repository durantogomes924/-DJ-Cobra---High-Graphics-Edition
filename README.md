# 🐍 DJ Cobra - High Graphics Edition

A modern, upgraded version of the classic Snake game built with Python and Pygame. Features a polished user interface, glowing graphics, particle effects, and multiple game modes!

![DJ Cobra Gameplay](https://img.shields.io/badge/Game-Snake-brightgreen) ![Python](https://img.shields.io/badge/Python-3.x-blue) ![Pygame](https://img.shields.io/badge/Pygame-2.x-yellow)

## ✨ Features

- **Full UI:** Main Menu, Mode Select, Level Select, Pause, and Game Over screens.
- **3 Game Modes:**
  - **Classic:** Normal walls and standard speed.
  - **Speed:** The snake gets faster every time you eat.
  - **Wrap:** The snake wraps around the edges of the screen (no walls).
- **5 Levels:** Higher levels increase the base speed and spawn purple obstacles.
- **High Graphics:**
  - Rounded snake segments with a glowing head.
  - Glowing food with a shine effect.
  - Particle explosions when eating.
  - Directional eyes that follow where the snake is moving.
  - Smooth, hover-animated UI buttons.
